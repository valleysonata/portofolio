A browser-based macOS Sequoia desktop with a working terminal, Safari browser, Spotify player, Finder, Photos, VS Code, Launchpad, and an AI assistant. No frameworks, no build tools, just HTML/CSS/JS.

### Features

- Apple boot screen with loading bar
- macOS menu bar with Spotlight search, Control Center, Wi-Fi toggle, battery indicator
- Glassy dock with bounce animations
- Draggable and resizable windows with genie effect
- Terminal with ASCII matrix rain and AI chat agent
- Safari browser with CORS proxy fallback
- Spotify player with real iFrame embed
- Finder with virtual file system, create/delete/rename files and folders
- Photos gallery with lightbox
- VS Code with Monaco Editor
- Launchpad with app search
- Desktop with folder icons and files
- Mobile-responsive fallback

### Tech stack

| Layer | Tech |
|---|---|
| Markup | HTML5 |
| Styling | CSS3 |
| Logic | Vanilla JavaScript |
| AI | Groq AI via Cloudflare Worker |
| Hosting | GitHub Pages |

### Local development

```bash
git clone https://github.com/valleysonata/portofolio.git
cd portofolio
npx serve .
```

Open [http://localhost:8000](http://localhost:8000).

### Deployment

Push to `main` — auto-deploys to [valleysonata.github.io/portofolio](https://valleysonata.github.io/portofolio/).
